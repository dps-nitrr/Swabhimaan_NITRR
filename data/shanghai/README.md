\# Derived data: Shanghai T2DM



Converted from the Shanghai T2DM dataset by src/convert\_shanghai.py.



Original data: Zhao Q. et al., "Chinese diabetes datasets for data-driven machine learning", Scientific Data 10, 35 (2023). https://doi.org/10.6084/m9.figshare.c.6310860



Licence: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).



Changes made: timestamps normalized, diet and insulin text converted to numeric carbohydrate estimates and insulin units, selected lab values and demographics kept, HbA1c converted from mmol/mol to %.
